청원학교 카페봇 — 한국어·영어·중국어 신경망 합성 음성 v4

중요: 실제 사람의 녹음이 아닙니다. Microsoft Edge 신경망 합성 음성으로 새로 생성했습니다.
기존 macOS 목소리 파일을 복사하거나 이름만 바꾼 자료가 아닙니다.
특정 실존 인물의 목소리를 복제하지 않았습니다. 생성 문구와 목소리는 정답표에 기록했습니다.

[학습용 ZIP 사용]
1. 청원학교_3개언어_음성학습용.zip을 먼저 풉니다.
2. 티처블 머신의 새 오디오 프로젝트를 엽니다.
3. 아메리카노, 카페라떼, 배경 소음 세 칸을 준비합니다.
4. 각각의 칸에서 오디오 업로드를 선택하고, 이름이 일치하는 내부 ZIP을 넣습니다.
   아메리카노_티처블머신에넣기.zip → 아메리카노 칸
   카페라떼_티처블머신에넣기.zip → 카페라떼 칸
   배경_소음_티처블머신에넣기.zip → 배경 소음 칸
   바깥의 전체 묶음 ZIP을 한 칸에 넣지 않습니다.
5. 모델을 학습한 뒤 내보내기 → 모델 업로드를 합니다.
6. 새 모델 링크를 앱 ⑤에 붙여 연결합니다. 이전 모델은 자동으로 바뀌지 않습니다.

[테스트용 ZIP 사용]
1. 테스트용 ZIP을 풀고, 앱 ⑥에서 소리 파일 올리기를 선택합니다.
2. 메뉴주문 폴더의 WAV를 선택하고 듣고 AI 예측을 누릅니다.
3. 소리를 먼저 듣고 실제 메뉴와 예측이 같은지 비교합니다.
4. 배경확인 폴더의 WAV는 메뉴가 나오지 않고 판단 보류가 되는지 확인하는 자료입니다.
테스트용은 학습에 넣지 않습니다. 테스트용 목소리는 학습에 사용하지 않은 별도 합성 목소리입니다.

[문구]
한국어: 아메리카노 / 카페라떼, 그리고 주세요·한 잔 주세요 등의 짧은 주문.
영어: Americano / Caffè latte·latte, 그리고 please를 포함한 짧은 주문.
중국어(보통화): 美式咖啡 / 拿铁, 그리고 一杯·请给我一杯를 포함한 짧은 주문.
중국어를 한국어 '아메리카노·카페라떼'로 읽지 않고 현지 표현으로 생성했습니다.

[구성]
학습 원본 주문 WAV 36개 + 학습 배경 WAV 72개.
테스트 주문 WAV 12개(언어당 두 메뉴 × 두 문구) + 배경 WAV 12개.
TM 업로드 ZIP은 주문 원본에서 약 1초 구간과 약한 잡음 추가 구간을 만든 파생 학습 표본입니다.
파생 구간 수는 서로 다른 사람 수가 아닙니다. 목소리는 학습 6종, 테스트 3종입니다.
배경은 절차적으로 만든 합성 잡음이며 실제 교실 녹음이 아닙니다.

[검증 범위]
음원 형식·무음 여부·ZIP 구조·학습/테스트 중복 여부를 점검했습니다.
티처블 머신에서의 실제 새 모델 학습·업로드·정확도는 아직 검증하지 않았습니다.
합성 음성 파일 실습용입니다. 학생의 실제 마이크 음성 인식 성능을 보장하지 않습니다.

[생성 도구]
edge-tts 7.3.1: https://github.com/rany2/edge-tts
Microsoft Edge 온라인 신경망 음성 서비스. 도구의 라이선스는 출력 음원의 별도 이용 허가를 뜻하지 않습니다.
출력 음원에 실제 사람 녹음 또는 공개 라이선스 사람 녹음이라는 표기를 하지 않습니다.
